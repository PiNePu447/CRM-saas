# Template de Projetos Padrao

Repositorio base para iniciar novos projetos com padroes minimos de colaboracao.

## Inclui

- `.gitignore` inicial
- templates de Issue (bug e feature)
- template de Pull Request
- configuracao para desabilitar issue em branco

## Como usar

1. No GitHub, clique em **Use this template**.
2. Crie um novo repositorio com nome e visibilidade desejados.
3. Aplique protecao da branch `main` nas configuracoes do novo repositorio.
